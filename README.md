# ספר המתכונים: אפליקציה בחינם

גרסה שאפשר להתקין בטלפון אנדרואיד כמו אפליקציה רגילה. אין בה שום דבר בתשלום, ואין צורך בחשבון Claude.
המתכונים נשמרים בטלפון של אמא, והאפליקציה עובדת גם בלי אינטרנט.

## מה בפנים
- `index.html` האפליקציה עצמה
- `manifest.webmanifest` ו-`icon-*.png` שם, אייקון ותצוגה כאפליקציה
- `sw.js` עבודה בלי אינטרנט

## מה עובד
המטבח שלי: לוח "השבוע שלי" ו"המתכונים שלי" עם קטגוריות (בוקר, צהריים, ערב, סלטים, קינוחים ואפייה, טיגונים, מרקים), חיפוש, מועדפים, עריכה ומחיקה עם ביטול. תיעוד בכתיבה, בקול (זיהוי הקול של Chrome) ובתמונה.
הוספת קבצים: קבצי טקסט מ-Samsung Notes (שורה ראשונה = שם המתכון), תמונות וקבצי גיבוי. דף השראה עם 12 מתכונים קלאסיים.
גיבוי ושחזור, וכתב גדול.

## מה לא כלול (כי זה עולה כסף)
זיהוי אוטומטי של מנה מתמונה, קריאת כתב יד, והצעות מותאמות אישית. בדף ההשראה יש רשימה קבועה.
התראות "מה הכנת היום?" לא אמינות באפליקציה מסוג זה. אפשר להוסיף אותן בגרסת ה-APK מהפרויקט הקודם.

## שלב 1: להעלות לאינטרנט בחינם (בחר דרך אחת)

### דרך א: GitHub Pages
1. פתח חשבון חינם ב-github.com.
2. New repository, שם: recipes, חייב להיות Public. Create.
3. Add file, Upload files, גרור פנימה את כל הקבצים מהתיקייה (לא את התיקייה עצמה), Commit.
4. Settings, Pages, Source: Deploy from a branch, Branch: main, תיקייה: /(root), Save.
5. אחרי דקה-שתיים הכתובת תופיע שם: https://השם-שלך.github.io/recipes/

הקוד גלוי לכולם, אבל המתכונים של אמא לא: הם נשארים רק בטלפון שלה.

### דרך ב: Netlify Drop
1. היכנס ל-app.netlify.com/drop.
2. גרור את התיקייה לדף. תקבל כתובת מיד.
3. פתח חשבון חינם כדי שהאתר לא יימחק אחרי זמן קצר.

## שלב 2: להתקין אצל אמא
1. שלח לה את הכתובת בוואטסאפ.
2. היא פותחת אותה ב-Chrome.
3. שלוש נקודות בפינה, ואז "התקנת אפליקציה" (או "הוספה למסך הבית"). אפשר גם דרך הגדרות באפליקציה, כפתור "התקנת האפליקציה".
4. אייקון חדש יופיע במסך הבית, והוא נפתח במסך מלא כמו אפליקציה.

## עדכונים
כשמשנים את `index.html`, העלה אותו שוב ושנה בקובץ `sw.js` את `rb-v1` ל-`rb-v2`, כדי שהטלפון יטען את הגרסה החדשה.

## אופציונלי: קובץ APK אמיתי, גם בחינם
באתר pwabuilder.com מדביקים את הכתובת ובוחרים Package for Android. מורידים APK ומתקינים בלי חנות.
פרסום ב-Google Play עולה כסף חד פעמי, ואין בו צורך.

## חשוב
- המתכונים נשמרים בזיכרון של האפליקציה בטלפון. מחיקת נתוני Chrome או הסרת האפליקציה תמחק אותם, לכן כדאי ללחוץ מדי פעם על "שמירת גיבוי" בהגדרות ולשמור את הקובץ בדרייב או בוואטסאפ.
- שחזור: בהגדרות, "שחזור מגיבוי".
